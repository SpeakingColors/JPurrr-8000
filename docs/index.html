JPurrr-8000

STUDIO 87 · free and open source synthesizer

A free VST3 and standalone synth in the spirit of the late 90s JP-8000 and JP-8080: Super Saw, filter, LFOs, arpeggiator and effects, plus our own FX page that makes every sound mix ready. For Linux, Windows and macOS. Works 100% offline.

Download the latest release Manual (PDF) Source code Ko-fi

What is in it

Sound page

  • Super Saw and the other oscillators
  • 12 or 24 dB filter, envelopes, two LFOs
  • Arpeggiator, key modes (single, dual, split)
  • Chorus, flanger, phaser, distortion and delay

FX page: CHAIN

  • Trance gate with a drawable 16 step pattern
  • Drive stack, low end, M/S EQ, transient shaper, resonance tamer
  • Glue compressor, widener, slow auto pan

FX page: MASTER

  • Opto leveller and OTT style squeeze
  • Four band compressor and limiter
  • Soft clipper and true peak limiter

Made for production

  • Live displays that move with the sound
  • 51 factory sounds, your own banks, preset browser
  • Resizable window, four colour looks
  • Presets as plain text (JSON)

Presets: your own JSON format, plus JP-8000 and JP-8080 SysEx import and JP-8080 SysEx export. MIDI CC and NRPN control is documented. The manual says exactly what is in each version.

Install

Windows

Download JPurrr-8000-<version>-Windows-x64-Setup.exe and run it. SmartScreen may warn because the setup is not signed: More info, then Run anyway.

macOS

Open JPurrr-8000-<version>-macOS.pkg (Apple silicon and Intel). It is not notarized: on macOS 14 and older right click, Open; on macOS 15 and newer use System Settings, Privacy & Security, Open Anyway.

Linux

Unpack JPurrr-8000-<version>-Linux-x86_64.tar.gz and run ./install.sh. It installs for your user, no root needed. Or copy JPurrr-8000.vst3 to ~/.vst3/.

Close your DAW first, then rescan plugins. Every release lists a SHA-256 checksum for each file.
